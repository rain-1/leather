Idea: Minimal agentic harness for working with AI models over an API like https://dev.synthetic.new/docs/openai/chat-completions
We want this to be as minimal in terms of dependencies as possible
The agents will run starting in a directory on your local computer, starting a chat will require picking a location to work in
settings like this will be visible and apparent to the user

We want a clean design, meaningfully decompose the implementation into self contained files, use only essential and common libraries to implement this

The agent needs to be able to execute tool calls, primarily:
* searching the web and reading web pages
* creating and editing code files in the current repo
* run commands (e.g. build and run the code, test it, git commit, etc.)
* agents have names and there is a channel for them to communicate with each other (basically just queue up prompts for each other)
* ability for the agent to set prompted 'watchers' e.g. a timer, or observe some file change and get triggered by it to continue working

in terms of user interface, we primarily want to have work from a web interface that connects to a separate backend service that manages the agents (meaning handles the streaming of the API calls and also launching off the processes and capturing the output to give back to the agents)
* dashboard that shows every agent and which chat they are part of
* individual chats with LaTeX/MathJax support, support the ability to branch at any point, to export a single chat or all chats as JSON
* chat messages should be markdown, and we want a way for the AI to show images to me inline in chat (e.g. if it generates an jpg, png or SVG image using a python script), more generally ability to give me artefacts to interact with like a little HTML page with a UI to let me explore and try stuff out (e.g. if I ask for a mathematical visualization in three.js)
* ability to see exactly which model produced any message
everything should be stored in some kind of persistence database for easy/fast querying loading up, adding to etc.
